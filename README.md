1 .버전관리 개요 정리
02. 1-2 버전관리 개요
1) 버전 관리의 필요성
파일 작업을 하다 보면 과거 어느 시점의 상태로 되돌아가고 싶을 때가 있다.
예전에는 파일 이름을 바꿔가며 여러 버전을 저장하거나, 아예 폴더를 복사해서 관리했지만, 파일이 많아질수록 비효율적이다.
버전 관리는 이러한 문제를 해결하기 위해 파일의 변경 이력 전체를 체계적으로 기록하고 추적하는 기능을 제공한다.
2) 버전 관리란?
시간이 흐르면서 파일이 어떻게 달라졌는지 기록하는 시스템
누가, 언제, 어디를, 어떻게 수정했는지 확인 가능
필요한 경우 특정 시점으로 ‘시간여행’처럼 되돌아갈 수 있음
여러 사용자가 동시에 작업할 때 충돌을 해결하는 기반 제공
3) 버전관리 도구의 방식
CLI(Command Line Interface): Git Bash처럼 텍스트 기반으로 명령을 입력
GUI(Graphical User Interface): 소스트리 등 그래픽 화면으로 직관적 사용 가능
4) 커밋(commit) 개념
현재 프로젝트 상태를 저장하는 ‘스냅샷’
파일의 변경 이력을 저장소에 기록하는 행위
커밋이 순서대로 쌓이며 버전 히스토리가 형성됨
가장 최근 커밋을 가리키는 포인터 = HEAD
5) 지역 저장소와 원격 저장소
지역(Local) 저장소: 내 컴퓨터 안의 저장소
원격(Remote) 저장소: 깃허브 같은 서버 기반 저장소
관련 명령어
clone: 원격 저장소 복제
add: 변경사항 스테이징
commit: 스냅샷 저장
push: 지역 → 원격
pull: 원격 → 지역

2. 깃과 깃허브 개요 정리
03. 1-3 깃과 깃허브 개요
1) Git의 탄생과 특징
Git은 2005년 리누스 토르발스가 개발한 분산 버전 관리 시스템이다.
모든 개발자는 자신의 PC에 전체 소스 코드 복사본을 가지고 있어 빠르고 안정적이다.
2) Git의 주요 기능
파일의 변경을 시간순으로 추적
여러 개발자가 독립적으로 작업 후 합치기(merge) 가능
브랜치를 활용한 비선형 개발 가능(여러 버전 동시에 개발)
3) Git의 내부 구조
Working Directory(작업 폴더): 실제 작업하는 공간
Staging Area: 커밋할 변경 사항을 모아두는 공간
Repository(.git): 모든 버전 기록이 저장되는 공간
Stash: 잠깐 저장하는 임시 공간
add → commit → push 구조로 상태가 이동한다.
4) 브랜치 개념
‘나무 가지’처럼 기존 코드를 복사해 독립적으로 개발하면서도
필요하면 다시 메인 브랜치와 merge할 수 있는 방식
새로운 기능 개발, 실험용 작업을 안전하게 수행할 수 있음
5) GitHub란?
Git 저장소를 온라인에서 관리할 수 있는 플랫폼
협업, 코드 리뷰, 문서화 등 다양한 기능 제공
무료 계정은 공개 저장소 기본 제공, 비공개는 유료
전 세계 개발자들이 함께 사용하는 대표적인 오픈소스 플랫폼

4. 깃 설정과 저장소 생성 정리
1) Git 최초 설정
새 PC에서 Git을 사용하기 전에 딱 한 번 해두는 설정들이 있다.
필수 6가지 설정
git config --global user.name "사용자이름"
git config --global user.email "이메일"
git config --global core.autocrlf true       # 줄바꿈 자동변환(Windows)
git config --global core.safecrlf false      # 줄바꿈 오류 방지
git config --global core.editor "code --wait"  # 기본 편집기
git config --global init.defaultBranch main    # 기본 브랜치 이름
모두 전역 설정 파일(~/.gitconfig)에 저장되어 이후 다시 설정할 필요 없다.
2) Git 저장소 생성
프로젝트 폴더를 Git 저장소로 만들기 위해 git init 사용한다.
두 가지 방식
git init : 현재 폴더를 저장소로 변경
git init 폴더명 : 새로운 폴더를 만들고 저장소 생성
생성을 마치면 .git 폴더가 자동으로 생성되며, 여기에 모든 버전 기록이 저장된다.
.git 폴더를 삭제하면 저장소 기능이 사라지므로 주의해야 한다.
